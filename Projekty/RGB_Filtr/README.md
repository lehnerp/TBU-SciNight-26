# RGB Filter

A Czech-language GUI for text/QR codes in colored layers, previews,
and PNG/PDF export. This project has no Arduino counterpart or hardware wiring.

- **Run:** `python Filter_Text_QE.py` or `python main.py`.
- **Requirements:** Tkinter, numpy, Pillow, qrcode, reportlab.
- **Working directory:** this project's folder; create the environment using the [shared guide](../README.md).
- **Install:** `python -m pip install -r requirements.txt`.
- **Usage:** select a layer type, text, and variant, then export.
